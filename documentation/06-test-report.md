# گزارش تست واقعی

تاریخ: ۲۶ نوامبر ۲۰۲۶ (۵ آذر ۱۴۰۵). محیط اجرای تست Linux x64 است؛ اجرای مستقیم روی macOS انجام نشده است.

## محیط و نسخه‌ها

- .NET SDK: `10.0.404`؛ Target Framework: `net10.0`.
- EF Core SQLite و dotnet-ef: `10.0.14`.
- سرور واقعی Kestrel با HTTP روی پورت موقت آزاد.
- SQLite واقعی در یک پوشه موقت؛ پس از تست حذف شد.
- Python 3 با کتابخانه استاندارد برای HTTP/SQLite/process؛ بدون mock بک‌اند.
- Node `24.22.3` برای تست adapter دمو با localStorage شبیه‌سازی‌شده؛ بدون browser rendering.

## نتایج

| بررسی | نتیجه واقعی |
|---|---|
| Restore وابستگی‌ها | موفق |
| Build چهار پروژه | موفق؛ صفر Warning و صفر Error |
| تولید InitialCreate با dotnet-ef | موفق؛ Migration، Designer و Snapshot همراه سورس |
| ساخت DB تازه با Migration | موفق |
| تطبیق مدل با Snapshot | `No changes have been made to the model since the last migration.` |
| تولید SQL از Migration | موفق؛ `schema.sql` |
| تست یکپارچه API/MVC/SQLite | **۳۸ بررسی موفق** |
| تست منطق دموی مستقل | **۱۸ بررسی موفق** |
| بررسی syntax فایل‌های JavaScript | موفق |
| بررسی وجود assetها و یکسان بودن فایل‌های مشترک UI | موفق |
| بررسی تصویری و کلیک در مرورگر واقعی | انجام نشد؛ محدودیت دسترسی محیط |
| انتشار GitHub Pages / push مخزن | انجام نشده؛ `docs/` آماده انتشار است |

Build موازی پیش‌فرض در این محیط بدون پیام compiler موفق نشد. اجرای تک‌پردازه با `dotnet build -m:1 --disable-build-servers` موفق شد. دستورهای README به همین دلیل از `-m:1` استفاده می‌کنند. هیچ خطای compiler باقی نمانده است.

## پوشش تست بک‌اند

- ساخت، خواندن، ویرایش و حذف دانشجو، مدرس، جلسه و ارزیابی.
- statusهای 200، 201 و Location، 204، 400، 404 و 409.
- نام فقط فاصله، ایمیل نامعتبر/تکراری با تفاوت حروف، طول نام بیش از حد.
- تاریخ نامعتبر/خالی، پیشرفت خارج بازه، مدرس ناموجود، شرکت‌کننده ناموجود/تکراری/غیرفعال.
- ثبت و ویرایش حضور؛ محاسبه دقیق ۵۰٪ و ۱۰۰٪؛ PUT تکراری.
- رد atomic فهرست ناقص/تکراری، دانشجوی خارج جلسه، enum نادرست، enum عددی و null.
- جلسه بدون شرکت‌کننده و حضور `null`؛ بدون تقسیم بر صفر.
- اضافه شدن دانشجو و غیرفعال شدن فرد قدیمی، تعداد/آمار جلسه قبل را عوض نمی‌کند.
- جلوگیری از حذف افراد دارای سابقه؛ حذف پس از برداشته شدن وابستگی‌ها.
- امتیاز خارج ۰–۱۰۰، ارزیابی تکراری و ارزیابی فرد خارج از جلسه رد می‌شود.
- حذف جلسه حضور و ارزیابی وابسته را cascade می‌کند.
- توقف واقعی process و راه‌اندازی دوباره؛ امتیاز و حضور باقی می‌ماند.
- `PRAGMA foreign_key_check` بدون خطا؛ Migration پس از restart دوباره ثبت نمی‌شود.
- سرو شدن index اصلی از wwwroot؛ MVC GET/POST، model binding، خطای نام خالی و antiforgery.
- وجود لاگ HTTP Middleware و لاگ جداگانه شروع/پایان Action.
- اسکریپت seed واقعاً ۱۲ دانشجو و ۶ جلسه در DB ایجاد می‌کند؛ اجرای دوباره روی DB غیرخالی بدون درج داده متوقف می‌شود.

## پوشش تست دمو

داده اولیه، CRUD، محاسبه حضور، ثابت بودن roster، جلوگیری از حذف افراد مرجع‌دار، ارزیابی تکراری، cascade، بازخوانی از localStorage شبیه‌سازی‌شده، rollback در خطای ذخیره، reset و صفر بودن فراخوانی Fetch بررسی شد. این تست جایگزین آزمون مرورگر یا بک‌اند نیست.

## محدودیت‌های صریح

Chromium قابل اجرای محلی در محیط موجود نبود؛ دریافت مرورگر تست نیز موفق نشد. مرورگر ابری به سرور localhost این اجرا دسترسی نداشت. بنابراین شباهت بصری به تصاویر، نبود اسکرول در viewportهای مختلف، ترتیب focus، رفتار dialog، بارگذاری واقعی فونت و کلیک‌های UI **تأیید بصری نشده‌اند**. طراحی برای دسکتاپ معمولی با ۶ کارت (عرض متوسط ۴ کارت) و pagination نوشته شده است؛ موبایل و ارتفاع بسیار کم اسکرول طبیعی دارند.

تست روی مک، Safari، عملکرد زیر بار، رقابت هم‌زمان و تزریق عمدی خطای غیرمنتظره 500 اجرا نشده‌اند. خطای کسب‌وکار 409 و ProblemDetails دارای traceId اجرا شده‌اند؛ مسیر عمومی 500 در کد وجود دارد ولی تست تزریق خطا ندارد. این گزارش ادعای تست‌شدن آن‌ها را ندارد.

## بازتولید

از ریشه پروژه:

```bash
dotnet tool restore
dotnet build -m:1
python3 tests/smoke.py
node tests/demo.mjs
```

برای SDK در مسیر سفارشی، متغیر `BOOTCAMP_DOTNET` را مسیر فایل اجرایی dotnet قرار دهید. تست API دیتابیس App_Data شما را تغییر نمی‌دهد. خروجی واقعی آخرین اجرای تست API در [test-output.txt](test-output.txt) قرار دارد.
